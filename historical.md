# Historical Poker Resources

Historically important poker resources that are useful for research context, but may not meet the maintenance bar for the main list.

## Computer Poker

- [ACPC Server](https://github.com/crissilvaeng/acpc-server) - Server code for the Annual Computer Poker Competition.
- [Cepheus](https://poker.srv.ualberta.ca/about) - University of Alberta project that essentially solved heads-up limit Texas hold'em.
- [ACPC Google Group](https://groups.google.com/g/computer-poker) - Announcement archive for the Annual Computer Poker Competition community.

## Hand Histories

- [PokerHandHistoryParser](https://github.com/HHSmithy/PokerHandHistoryParser) - Older parser for extracting game metadata and actions from poker hand histories.

## Solvers

- [postflop-solver](https://github.com/b-inary/postflop-solver) - Suspended Rust postflop solver library for Texas Hold'em.
- [WASM Postflop](https://github.com/b-inary/wasm-postflop) - Suspended browser-based Texas Hold'em GTO solver built with WebAssembly.
